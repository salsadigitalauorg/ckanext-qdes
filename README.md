# ckanext-qdes

CKAN extension for QDES catalogue reporting and dashboard functionality.

## Tests

Run these commands from the repository root:

```bash
ahoy run cli "cd /app/src/ckanext-qdes && pytest ckanext/qdes/tests"
```

Run a specific test file:

```bash
ahoy run cli "cd /app/src/ckanext-qdes && pytest ckanext/qdes/tests/test_csv_reports.py"
```
